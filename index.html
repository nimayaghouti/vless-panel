VLESS Panel

Create a token: use the search box at the top of the Cloudflare dashboard, search for "API Tokens", open it, then Create Token → Custom token. Add only these two permissions: Account / Workers Scripts / Edit and Account / Account Analytics / Read, and set Account Resources to your account. Cloudflare shows the token only once — save it somewhere safe before closing that page.

This token goes straight from your browser to Cloudflare's own servers; this project has no external server of its own — server.js is a few dozen lines you can read yourself.

Find your Account ID in the dashboard sidebar under Build → Compute → Workers & Pages (right-side panel). Your workers.dev subdomain is already set up there too — no need to configure it.

Heads up: Cloudflare Workers can't connect back to Cloudflare's own network. If your device is connected through the VLESS config below while you use this panel, verify/deploy/usage requests here will fail — and once connected, the Cloudflare dashboard itself won't load through that same tunnel either.
